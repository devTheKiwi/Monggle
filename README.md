# 몽글 (Monggle)

맥 메뉴바에 사는 작고 반짝이는 미니 캘린더.

macOS 캘린더 · 미리 알림과 바로 연결되고, 메뉴바에 오늘 날짜를 원하는 형식으로 띄웁니다.
네이티브 Swift + SwiftUI로만 만들었고 외부 의존성이 없습니다.

## 기능

- **메뉴바 표시 형식** — 아이콘 / `24` / `7월 24일 (금)` / `2026.07.24` / `20260724` 등 8가지 프리셋, 또는 `DateFormatter` 패턴 직접 입력
- **컬러 & 배경** — 포인트 색 테마 5종(코랄·라벤더·민트·하늘·버터), 배경 알약 4종(없음·연하게·테두리·꽉 채우기)
- **반짝임** — 주기마다 광택이 훑고 지나가며 별이 반짝임 (끔 / 은은하게 / 반짝반짝)
- **이모지** — 날짜 앞에 원하는 이모지, 원래 색 그대로
- **달력** — 캘린더 일정 + 미리 알림을 날짜별 점으로, 선택한 날의 목록은 아래에. 할 일은 클릭해서 완료 처리
- **한국 공휴일** — 음력·대체공휴일 포함 (2026~2027 수록)
- 주 시작 요일(일/월), 로그인 시 자동 시작, 자정 자동 갱신

## 빌드

macOS 14.0 이상, Xcode 커맨드라인 도구 필요.

```sh
make run       # 빌드 후 바로 실행
make install   # /Applications 에 설치하고 실행
make clean
```

## 구조

| 파일 | 역할 |
|---|---|
| `App.swift` | `NSStatusItem` + `NSPopover` 구성 |
| `MenuBar.swift` | 메뉴바 라벨 렌더링, 반짝임 타이머 |
| `Popover.swift` | 달력 그리드와 일정 목록 |
| `Settings.swift` | 설정 창 |
| `Prefs.swift` | 설정 값 (UserDefaults) |
| `Sparkle.swift` | 반짝임 · 광택 효과 |
| `AppState.swift` | EventKit 연동 |
| `Support.swift` | 색 테마, 날짜 유틸, 공휴일 표 |

### 메뉴바에 색을 넣은 방법

SwiftUI `MenuBarExtra`는 라벨을 템플릿 이미지로 평탄화해서 색이 전부 사라집니다.
그래서 `NSStatusItem`을 직접 만들고, SwiftUI 뷰를 `ImageRenderer`로 구운 뒤
`isTemplate = false`로 넣어 색을 유지합니다. 반짝임은 상시 애니메이션 대신
주기마다 1.25초씩만 24fps로 다시 그려 배터리 부담을 줄였습니다.

## 공휴일 갱신

음력·대체공휴일은 `Support.swift`의 `Holidays.table`에 연도별로 적어둡니다.
새 연도가 필요하면 그 표에 한 줄씩 추가하면 됩니다.
