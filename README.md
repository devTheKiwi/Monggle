# 몽글 (Monggle)

맥 메뉴바에 사는 작고 반짝이는 미니 캘린더.

macOS 캘린더 · 미리 알림과 바로 연결되고, 메뉴바에 오늘 날짜를 원하는 형식으로 띄웁니다.
네이티브 Swift + SwiftUI로만 만들었고 외부 의존성이 없습니다.

## 기능

- **메뉴바 표시 형식** — 아이콘 / `24` / `7월 24일 (금)` / `2026.07.24` / `20260724` 등 8가지 프리셋, 또는 `DateFormatter` 패턴 직접 입력
- **컬러 & 배경** — 포인트 색 테마 5종(코랄·라벤더·민트·하늘·버터), 배경 알약 4종(없음·연하게·테두리·꽉 채우기)
- **반짝임** — 주기마다 광택이 훑고 지나가며 별이 반짝임 (끔 / 은은하게 / 반짝반짝)
- **이모지** — 날짜 앞에 원하는 이모지, 원래 색 그대로
- **달력 스킨 5종** — 기본 · 솜사탕 · 유리 · 밤하늘(별) · 오로라(흐르는 빛)
- **달력** — 캘린더 일정 + 미리 알림을 날짜별 점으로, 선택한 날의 목록은 카드로. 일정마다 캘린더(카테고리) 색과 이름, 종료 시각, 장소 표시
- **일정 연동** — 일정 줄을 누르면 캘린더 앱에서 열리고, `+` 버튼으로 몽글에서 바로 일정 추가 (시작·종료 시각, 캘린더 선택)
- **인앱 자동 업데이트** — GitHub 릴리스를 확인해 새 버전이면 배너 + 버튼으로 교체·재실행
- **한국 공휴일** — 음력·대체공휴일 포함 (2026~2027 수록)
- 주 시작 요일(일/월), 로그인 시 자동 시작, 자정 자동 갱신

## 빌드

macOS 14.0 이상, Xcode 커맨드라인 도구 필요.

```sh
make run       # 빌드 후 바로 실행
make install   # /Applications 에 설치하고 실행
make clean
```

## 새 버전 내보내기

앱에 인앱 업데이터가 들어 있어서, GitHub 릴리스만 올리면 사용자에게 "새 버전이 있어요"
배너가 뜨고 누르면 알아서 교체·재실행된다.

1. `Info.plist` 의 `CFBundleShortVersionString` 을 올린다 (예: `1.0` → `1.1`)
2. 바뀐 내용을 커밋한다
3. `make release` — 현재 버전으로 태그(`v1.1`)를 달고, `Monggle.zip` 을 첨부해 GitHub 릴리스를 만든다 (`gh` CLI 필요)

업데이터는 `api.github.com/repos/devTheKiwi/Monggle/releases/latest` 를 확인해
버전이 더 높으면 배너를 띄우고, 첨부된 `Monggle.zip` 을 받아 자기 자신을 교체한다.

> **공증(notarize) 참고** — 지금 빌드는 임시 서명(ad-hoc)이라 사용자가 *처음* 받을 때는
> Gatekeeper 경고가 뜬다(우클릭 → 열기 필요). 업데이트는 새 앱의 quarantine 을 벗겨서
> 경고 없이 실행된다. 경고를 완전히 없애려면 Apple Developer ID 로 서명·공증해야 한다.

## 구조

| 파일 | 역할 |
|---|---|
| `App.swift` | `NSStatusItem` + `NSPopover` 구성, 앱 델리게이트 |
| `MenuBar.swift` | 메뉴바 라벨 렌더링, 반짝임 합성 |
| `Popover.swift` | 달력 그리드, 일정 목록, 일정 추가 폼, 업데이트 배너 |
| `Settings.swift` | 설정 창 |
| `Prefs.swift` | 설정 값 (UserDefaults) |
| `Skin.swift` | 팝오버 스킨 5종 배경 |
| `Sparkle.swift` | 반짝임 · 광택 효과 |
| `Updater.swift` | GitHub 릴리스 확인 · 다운로드 · 자기 교체 |
| `AppState.swift` | EventKit 연동 (일정·미리알림 읽기/추가) |
| `Support.swift` | 색 테마, 날짜 유틸, 공휴일 표 |

### 메뉴바에 색을 넣은 방법

SwiftUI `MenuBarExtra`는 라벨을 템플릿 이미지로 평탄화해서 색이 전부 사라집니다.
그래서 `NSStatusItem`을 직접 만들고, SwiftUI 뷰를 `ImageRenderer`로 구운 뒤
`isTemplate = false`로 넣어 색을 유지합니다.

반짝임은 상시 애니메이션이 아니라 주기마다 1.25초씩만 켜집니다. 그마저도 매 프레임
SwiftUI를 다시 굽지 않고, 설정이 바뀔 때 한 번 구운 베이스 이미지 위에 광택과 별만
Core Graphics로 합성합니다 (반짝반짝 기준 CPU 평균 ~5%).

## 공휴일 갱신

음력·대체공휴일은 `Support.swift`의 `Holidays.table`에 연도별로 적어둡니다.
새 연도가 필요하면 그 표에 한 줄씩 추가하면 됩니다.
